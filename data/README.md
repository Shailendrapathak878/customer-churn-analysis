## 📌 Why Is the Dataset Not Uploaded?

The dataset used in this project was obtained from a Kaggle competition dataset.

The applicable Kaggle competition rules do not provide unrestricted permission to redistribute the dataset outside the permitted usage conditions.

To avoid unauthorized redistribution, the following dataset files have been intentionally excluded from GitHub:
